How it works

From prompt to synthesis

01
Pre-flight
Lead reads all input files. Picks a template (A, B, or C). Announces the team and waits 30s for abort.
02
Wave 1
Finders/researchers and contrarians spawn in parallel. Gemini runs independently from Anthropic models.
03
Wave 2
Arguers read Wave 1 outputs and push back. Aggregator reads everything and produces a ranked draft.
04
Synthesis
Lead reads every agent file in full, writes SYNTHESIS.md: vote tally, splits, judgment calls, recommendation.
Install

Get started in two minutes

Clone the plugin, set your output directory, then invoke the skill by name. 

# Install the plugin
git clone https://github.com/Damon-Stewart-1/claude-skills-public.git \
  ~/.claude/plugins/claude-skills-public

# Set your output directory (add to ~/.zshrc to persist)
export CLAUDE_AGENT_RUNS="${HOME}/claude-agent-runs"

# Invoke in any Claude Code session
/spawn-agent-team

See SKILL.md for team templates, model routing rules, and failure recovery.
